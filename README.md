# Arena do Trunks — Releases

Este repositório distribui os instaladores oficiais do Arena do Trunks.

Baixe `Arena-do-Trunks-Setup.exe` na seção **Releases** para instalar ou atualizar o app. `Arena-do-Trunks.exe` é a versão portátil.

Este repositório contém apenas informações de distribuição e os binários publicados. O código-fonte fica em um repositório privado separado.
